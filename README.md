# **Study of Formula 1 Constructors' Efficiency: A DEA and Cross-Efficiency Approach**

## **Overview**

This project evaluates how efficiently Formula 1 constructors convert available performance potential (starting positions and mechanical reliability) into competitive race results across the 2014–2023 hybrid era. Using an Input-Oriented Constant Returns to Scale (CCR) Data Envelopment Analysis (DEA) model combined with Cross-Efficiency Analysis, the study provides robust operational benchmarks for team principals and performance directors.

## **Key Features**

* **Data Sourcing & Processing:** Utilises race-by-race data from the Ergast F1 API (Kaggle dataset), processing 102 constructor-season Decision Making Units (DMUs).  
* **Operational Efficiency Scoring:** Evaluates self-efficiency frontiers where Mercedes, Ferrari, and Red Bull lead performance.  
* **Peer-Reviewed Stability Check:** Implements Doyle & Green's cross-efficiency matrix evaluation to eliminate self-appraisal bias and validate frontier robustness.

## **Variables**

* **Inputs (Minimised):** Average Starting Grid Position (pit-lane starts normalised to 20th), Mechanical DNF Rate.  
* **Outputs (Maximised):** Points Per Race, Average Positional Score.
